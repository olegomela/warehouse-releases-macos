# warehouse-releases-macos
Simple Warehouse App - .dmg releases

Stable basic WMS functionality (accounting).

Local standalone application.

Local database based on .csv files; preserved when uninstalling/reinstalling the application.

Interface languages:

  - 🇬🇧 English
  - 🇫🇷 French
  - 🇩🇪 German
  - 🇪🇸 Spanish
  - 🇺🇦 Ukrainian

Minimum Hardware Requirements

  - Processor (CPU): 1.6 GHz dual-core
  - Memory (RAM): 2 GB RAM
  - Storage: 300 MB free disk space
  - Display: 1280 x 720

Recommended Hardware Requirements

  - Processor (CPU): 2.0 GHz+ quad-core
  - Memory (RAM): 4 GB+ RAM
  - Storage: 1 GB+ free disk space
  - Display: 1920 x 1080 or higher

Operating System Requirements

  - Supported Versions: Windows 10+ (64-bit editions)
  - Architectures: x86_64 (Intel and AMD processors)
  - Requirements: Standard user permissions
